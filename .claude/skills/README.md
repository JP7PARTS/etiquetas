# Skills do projeto

Skills de design instaladas neste projeto para apoiar a renovação visual do app.

## Origem

Todas vêm do pacote **UI/UX Pro Max** (NextLevelBuilder), licença MIT:
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

| Skill            | Para que serve                                                        |
| ---------------- | -------------------------------------------------------------------- |
| `ui-ux-pro-max`  | Núcleo de design: estilos de UI, paletas, tipografia, guias de UX    |
| `design`         | Fluxo de design geral: identidade, tokens, logo, mockups             |
| `design-system`  | Criação e manutenção de design system                                |
| `ui-styling`     | Estilização de UI e geração de imagens (inclui fontes para canvas)   |
| `brand`          | Identidade de marca                                                   |
| `banner-design`  | Banners para social/ads/web/print                                     |
| `slides`         | Apresentações em HTML                                                 |

> Observação: as skills `design` e `slides` têm o mesmo nome de skills embutidas
> do Claude Code; dentro deste projeto, estas versões (de projeto) têm precedência.

O pacote **superpowers** (obra/superpowers) foi avaliado mas não instalado por
ser voltado a fluxo de desenvolvimento (TDD, debugging, code review), não a design.
